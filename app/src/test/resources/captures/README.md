# Jeux de test des lecteurs

Ces fichiers ont **la forme documentée par la communauté** de l'API d'ÉcoleDirecte (clés, types,
imbrications). Ce ne sont **pas** des captures réelles : toutes les valeurs sont inventées.

Pour les remplacer par des formes réelles : dans l'application, Plus → « Diagnostic des données »
→ Copier. Le texte copié ne contient que des clés, des types et des tailles (jamais une valeur) ;
il suffit pour récrire ces fichiers avec les vraies clés de ton établissement.
